What we'd change

What we foundProposed change
The page never says what the hat is for. Shoppers ask by activity, and a big retailer's listing tags it for hiking and paddling, but the brand's own page doesn't.Add a short "Best for" line: hiking, fishing, paddling, travel. Reviews already back each one.
The description that machines read opens with a press quote, not with what the hat is.Lead with the facts: UPF rating, brim width, weight, chinstrap. Keep the quote lower down.
Materials are described differently in different sections of the page.One clear materials line per color.
A few colors are heavily discounted on the brand's site, but ChatGPT only quoted the full price.Not a data error. Worth knowing: the best deal on the brand's own site isn't reaching the answers.
Structured data is complete (rating, review count, every color with price and stock), and robots.txt lets OpenAI's crawlers in.No change needed.

What it means

Brand B doesn't have a visibility problem: ChatGPT already knows it and likes Hat A when asked directly. The gaps are which product it names when shoppers ask by activity, and where it sends them. Those are what the pilot changes would target, and day 30 would show whether they moved.

How this check was done

Each question was asked up to 3 times in a temporary ChatGPT chat, starting fresh each time, on 24 November 2026. This was my first full run of the method: some answers were collected signed out and some signed in from Spain, which is why one answer showed a European shop. In a pilot, every run uses the same setup from a US location, on day 0 and on day 30.
